# Employee Attendance & Analytics API

FastAPI and MongoDB service for employee attendance, regularization, and analytics. Install dependencies with `pip install -r requirements.txt`, set `MONGO_URI` and `MONGO_DB`, then run `uvicorn app.main:app --port 8000`. The app creates its indexes at startup. MongoDB 6.0 or newer is required for the aggregation features.

Implementation notes and review findings are in `DECISIONS.md` and `REVIEW.md`.
